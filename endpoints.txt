# API Endpoints Documentation

This document provides a comprehensive list of all API endpoints available in the **projectsglobal** backend.

## Base URL
All API routes (except the testing route) are prefixed with `/api`.

---

## 📋 General / Form Submissions
Routes managed by `formRoutes.js`.

| Method | Endpoint | Middleware | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/submit-form` | `upload.single("profileFile")` | Submit a form with a profile file (Cloudinary) |
| `GET` | `/api/get-forms` | - | Get all submitted forms |
| `GET` | `/api/form/:formId` | - | Get a specific form by ID |
| `DELETE` | `/api/delete-form/:id` | - | Delete a form by ID |
| `GET` | `/api/dashboard-summary` | - | Get dashboard summary stats |
| `GET` | `/api/chart/monthly-submissions` | - | Get monthly submission counts |

---

## 🏗️ Projects (Public/Admin)
Routes managed by `projectRoutes.js`.

| Method | Endpoint | Middleware | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/projects/` | `upload.fields(...)` | Create a new project (Image & PDF) |
| `GET` | `/api/projects/` | - | Get all projects |
| `GET` | `/api/projects/live` | - | Get live projects |
| `GET` | `/api/projects/live-count` | - | Get live projects count |
| `GET` | `/api/projects/:id` | - | Get project by ID |
| `PUT` | `/api/projects/:id` | `upload.fields(...)` | Update a project |
| `DELETE` | `/api/projects/:id` | - | Delete a project |
| `PATCH` | `/api/projects/:id/update-applications` | - | Increment/Decrement application count |
